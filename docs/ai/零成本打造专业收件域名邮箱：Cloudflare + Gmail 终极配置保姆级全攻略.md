## 概述

本文档提供完整的Cloudflare + Gmail域名邮箱配置指南，帮助开发者快速实现专业级域名邮箱功能，无需额外成本。

## 前置条件

- 已注册的域名，并且已经接入 Cloudflare
- Google gmail账户
- 一个备用的邮箱，可以发送进行测试

## 配置目标

通过本教程，您将获得：

- 自定义域名邮箱地址（如 `yourname@yourdomain.com`）
- 完整的收发邮件功能
- 专业的企业级邮件服务

## 1. 打通收件服务（Cloudflare部分）

### 1.1 接入域名

1. 登录Cloudflare控制台
2. 在构建 -> 点击邮件服务 -> 电子邮件路由，这个页面选择右上角接入域名，选择你的域名
3. 点击完成即可接入

![image.png](https://img.zhengz.cc/PicGo/20260616160239955.png)

![image.png](https://img.zhengz.cc/PicGo/20260616160354791.png)

### 1.2 配置接入

1. 点击你的域名进入配置页面
2. 选择目标地址先添加你的谷歌邮箱
3. 选择路由规则，点击创建路由规则
4. 电子邮件匹配模式，输入你要转发的邮件地址，比如 hr@xxxx.com, 操作选择`发送到电子邮件`，目标输入你自己的谷歌邮箱，点击保存
5. 在路由规则tab，把全收规则和你创建的路由规则列表上的状态全部打开，变成活跃

## 2. 打通发件服务（Google Gmail部分）

### 2.1 开通谷歌邮箱的两步验证，生成应用专用密码

1. 登录Google 账号，打开Google账号的安全页,地址： https://myaccount.google.com/security
2. 在您的 Google 账号登录选项，把两步验证打开
3. 在当前账号页面，搜索`应用专用密码`，进入应用专用密码，创建您的应用专用密码
4. 名字随便输入，比如输入域名邮箱，创建弹出应用专用密码，复制一下保存好

###### 找不到“应用密码”入口，可能的两个原因：

- 你的账号还没开两步验证
- 你开了 `Advanced Protection`，Google 官方说明里明确写了，这种模式下应用专用密码不可用

![image.png](https://img.zhengz.cc/PicGo/20260616162058639.png)

### 2.2 谷歌邮箱添加对应的发件域名

1. 进入谷歌邮箱web版，地址: https://mail.google.com
2. 在右侧点击管理标签，选择顶部的`账号与导入`
3. 在用这个地址发送邮件，点击添加其他电子邮件地址
   - 名称: 填入你想发送邮件的名称
   - 邮箱: 填写你的邮箱地址，之前配置的那个， hr@xxxx.com
4. Treat as an alias` 这个选项，默认保留勾选就行。你本来就是在给同一个人加另一个发件地址
5. SMTP 配成这样
6. 在用这个地址发送邮件，点击添加其他电子邮件地址
	- SMTP: smtp.gmail.com
	- 端口：465
	- 用户名：你的 Gmail 完整地址
	- 密码：刚刚生成的 16 位应用专用密码(注意： 把刚才复制那个16位的空格删除)
	- 加密方式：SSL
7. 点击添加账号
8. 你的Gmail邮箱会收到一封确认邮件
9. 点击这份邮件里面的确认链接会打开一个页面，点击确认即可

## 3. 功能验证

测试邮件发送和接收

1. 用另一个邮箱发信到 `hi@你的域名.com`
2. 去 Gmail 收件箱里打开这封信，直接点回复
3. 发出去之前，看一眼 `From`，确认显示的是你的域名邮箱
4. 回到对方邮箱，确认能收到回复

### 4.3 常见问题排查

**无法接收邮件**：
- 检查MX记录配置
- 验证DNS传播状态
- 确认SPF记录正确

**邮件被标记为垃圾邮件**：
- 完整配置SPF、DKIM、DMARC记录
- 检查发件人信誉
- 避免大量群发邮件

**无法发送邮件**：
- 验证SMTP设置
- 检查发件人验证
- 确认账户权限
